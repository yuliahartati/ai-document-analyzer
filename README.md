# 📄 AI Document Analyzer

Analyze PDF and DOCX documents using AI to quickly extract summaries, key insights, important facts, claims, and action items.

This project demonstrates how AI can assist document understanding by converting long documents into structured information that is easier to review.

---

## Features

- 📄 Upload PDF and DOCX documents
- 📝 Generate concise summaries
- 💡 Extract key insights
- ✅ Identify important facts
- 📢 Detect claims and statements
- 📌 Highlight action items and recommendations
- 📥 Export analysis as Markdown report

---

## Supported Documents

- PDF (.pdf)
- Microsoft Word (.docx)

---

## Example Use Cases

- Summarize research papers
- Review business reports
- Analyze meeting minutes
- Extract key points from policy documents
- Review project documentation
- Read long reports faster
